# Source notes

Internal working notes, one per model. **Not published.** Nothing in this
directory is routed, linked or copied into a page as a block — a page takes
only the individual facts that help a buyer choose, in the page's own voice.

Each note separates two things that must never blur together:

- **Published in the product data** — a figure the catalogue prints. It is a
  rating from the manufacturer's literature, not a measurement taken here.
- **Not published** — what the catalogue does not say. These are the questions
  to put to the factory, and until they are answered the site does not state,
  imply or convert the missing value.

## Rules these notes follow

1. A catalogue figure is a rating. It is not a test report, a certification, or
   a guarantee of behaviour on a customer's material.
2. Where the catalogue contradicts itself, both readings are recorded. Neither
   is "corrected" into whichever one looks more sensible.
3. A standard named in a figure caption is a citation in that caption. It is not
   evidence that the product was tested to it.
4. No unit conversion, no derived value, no comparison against another brand.
